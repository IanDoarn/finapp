# FinApp

This repository contains a financial application with an automated setup script to help you get started quickly.

## Setup Instructions

The project uses a setup script that handles:
- Installation of `uv` package manager (if not already installed)
- Creation of a Python virtual environment
- Activation of the virtual environment

### Important: Running the Setup Script

The setup script must be run using the `source` command (or `.` in bash) to ensure the virtual environment is properly activated in your current shell:

```bash
source setup.sh
# or
. setup.sh
```
